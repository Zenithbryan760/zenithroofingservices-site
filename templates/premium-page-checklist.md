# Premium page delivery checklist

Copy this checklist into the working notes or pull request for every substantial Zenith page redesign.

## Preserve

- [ ] Page URL and all established internal links
- [ ] Form actions, methods, field names, hidden fields and validation
- [ ] reCAPTCHA, Netlify form attributes and submission behavior
- [ ] Analytics and conversion tracking
- [ ] Canonical, metadata and structured data
- [ ] Accurate existing business and service information

## Apply

- [ ] `/css/zenith-premium-exact.css`
- [ ] Approved Zenith colors and typography
- [ ] Premium sticky desktop header and full navigation
- [ ] Mobile menu with desktop-equivalent destinations
- [ ] Permanent Home, Call, Text, Estimate and Menu mobile dock
- [ ] Shared premium footer
- [ ] Real Zenith imagery and consistent icons
- [ ] Clear primary CTA and useful supporting CTA

## Verify

- [ ] 390px mobile layout
- [ ] 768px tablet layout
- [ ] 1024px compact desktop layout
- [ ] Wide desktop layout
- [ ] No horizontal overflow or clipped controls
- [ ] Images load and have useful alternative text
- [ ] No duplicate IDs or console errors
- [ ] Keyboard focus and 44px touch targets
- [ ] Reduced-motion behavior
- [ ] HTML/CSS and JSON-LD validation
- [ ] Deploy-preview visual inspection
